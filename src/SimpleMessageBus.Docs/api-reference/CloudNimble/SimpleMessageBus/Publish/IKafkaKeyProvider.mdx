## Summary

Interface for providing Kafka message keys. Implement this on your [IMessage](/api-reference/CloudNimble/SimpleMessageBus/Core/IMessage)
            types to control message partitioning in Kafka.

## Remarks




            Kafka uses message keys to determine which partition a message goes to. Messages with
            the same key always go to the same partition, ensuring ordering for related messages.

#### Syntax

```csharp
string GetKafkaKey()
```

#### Returns

Type: `string`
A string key that determines partition assignment. Return `null` to use
            round-robin partitioning (no ordering guarantee).
